# ChordFlow

> 结构驱动、语料增强的音乐和弦生成器：为主歌、副歌与桥段生成符合音乐规律、可控制熟悉度并带有过渡设计的完整和声方案。

ChordFlow 面向歌曲创作者、制作人与生成式音乐用户。它不是随机抽取四个和弦，而是先建立曲式和段落目标，再结合音乐理论、真实语料统计与生成算法，规划整曲的重复、对比、回归和边界张力。

## 产品愿景

项目的长期目标是构建经过许可审查、歌曲去重和统一归一化的百万级歌曲和弦图谱，并以此驱动可解释的谱曲算法：

- **符合音乐规律**：匹配用户设定的调性、听感、段落能量和张力解决。
- **降低雷同性**：识别高频路径与俗套风险，提供功能合理但相对少见的替代方案。
- **包含和弦设计**：生成主歌、副歌和桥段之间的连续关系，并处理转位、经过和弦、次属和弦、借用和弦与终止式变体。
- **服务后续制作**：输出 MIDI、结构化和弦数据，以及中英文 Suno 制作提示词包。

百万级语料是目标规模，不是当前仓库已经完成的能力。所有统计必须展示实际数据源、样本量和口径，不能包装成无条件的“全球使用率”。

## 当前版本

当前版本：`v0.28.0`

Riff 新增「重音方式」：原力度、主拍突出、弱拍推动。只调整已有旋律音的力度，不重生成音高、节奏或跨段衔接；经过音、预示音与引入音保持轻，问答/句尾根音保留支撑。4/4、3/4 按四分音符主拍，6/8 按附点四分音符分组；没有弱拍旋律音时不会自动补音或制造切分。网格亮度和悬停数值反映实际力度，试听、MIDI、WAV 与 Suno 说明同步；主题设置、撤销、JSON 和移调可恢复。旧工程仍用原力度，未增加依赖。重音是创作选择，不是审美评分，也不承诺等响度比较。

Riff 新增「段间衔接 → 段尾引入下一段」：在最后一个八分音符提前奏出下一段的实际首音，只接受同音或不超过两个半音的连接，不改写下一段动机。默认关闭；问答短句、根音收束、后段静音、曲尾或没有合适连接时保留原句。网格以橙色标出实际衔接音，Suno 蓝图只描述实际生成的结果。先按整曲生成 Riff，再截取单段，因此网格、单段/连段试听、单段/整曲 MIDI 和 WAV 使用同一份 Riff 音符；循环单段也保留指向原后段的尾音。改变后段会重新计算，工程仍只保存设置，不增加缓存、模型或依赖。这是规则式连接，不是“更好听”的保证。

「只换节奏 / 只换音高」现在支持有约束的动机变体：节奏可提前、后移、抽减和镜像，音高目标可反向、倒序、移位和收窄，最终仍适配当前和弦。每个维度由 3 个原型 × 8 类变换组成，切换时按当前段生成的基础音符跳过相同结果；这不是 24 种听感必然不同的保证。节奏和音高分别记录版本，旧工程（包括较大的旧种子）不会自动变音，点击哪个按钮就只升级对应维度。界面显示变体名称，贯通主题设置、撤销、JSON、MIDI、WAV 和 Suno 说明，无新增依赖。

本版完善核心创作链路：手动输入支持 `I V7/vi vi vii°7/V V` 等次属目标；Riff 可开启「弱拍预示」，在条件合适时提前一个八分音符奏出下一和弦的实际旋律落音，保护问句留白和句尾根音。实时 Riff 改用独立短尾音音源，增加「连前后段听 Riff」与纯 Riff / 和弦合奏 WAV 选择，并修正连段试听游标。盲听可选填和弦连接、和声色彩、熟悉程度或张力释放作为判断依据，随记录导出，不自动改变推荐。无新依赖、无后端。[核心链路审查与下一步](DEVELOPMENT_PLAN.md#16-v025-核心链路审查)。

Riff 新增「两小节问答」：第一小节末尾留一个主拍，第二小节呼应开头节奏和音高轮廓，最后落到该小节末和弦根音；和弦改变时，音高重新适配。支持 4/4、3/4、6/8（主拍为附点四分音符），加花不会填入问句末尾的留白。界面标出问句、答句与落点，设置贯通主题、撤销、JSON、MIDI、WAV 与 Suno 蓝图。问答模式固定两小节和句尾，旧工程仍按原循环播放；这是规则式乐句设计，不是已训练的旋律审美模型。

盲听默认加入「挖掘 vs 模板」对照，也可切回候选互选。相同条件下试听一组挖掘结果与一组内置模板，完整听完并选择后才揭示来源；可直接采用任一结果，继续生成 Riff 和 Suno 交付文件。模板只做循环移位以主和弦结束，不改写和弦顺序或性质；排除与模板循环相同的挖掘候选。分别统计偏好挖掘、偏好模板、差不多、都不喜欢及去重和弦对数，导出保留来源与模板 ID。这里的高熟悉度来自编辑先验，当前仅有大调、小调各两组循环家族，不是全球流行度基线；次数也不是独立样本或算法优越性的证明。

和弦挖掘支持上下文约束：次属和弦直接接向对应目标，前段已有的次属结尾会约束本段开头，也可为后段入口生成对应的属七连接；末段推荐以主和弦收束。排序同时参考前后段的声部移动，候选卡显示衔接距离、目标连接，并支持「连前后段听」。这是保守的自动搜索策略，不限制手动延迟解决或开放式结尾。盲听按独立片段重新生成收束候选；候选互选沿用算法 0.22，模板对照标记 0.23，兼容旧记录。

Riff 新增主题独立设置：默认编辑当前 A/B/C 主题，主歌、副歌可使用不同动机；重复字母沿用相同设置。支持全曲默认、主题静音与恢复继承。可开启弱拍经过音和句尾根音收束，音符网格分别以金色、粉色标识；经过音仅在同一和弦内有合适级进空间时插入。所有设置贯通试听、MIDI、WAV、JSON 和逐段 Suno 说明，和弦盲听仍排除 Riff。

「A/B 盲听挑和弦」随机分配播放标签，隐藏来源、名称与指标；统一音色、速度、拍号、两小节长度、转位方式及基础力度，并按发声音数近似补偿音量。完整听完两边后，可选更喜欢 A/B、差不多或都不喜欢，再揭示和弦并采用。最多保留最近 200 次本地选择，可导出 JSON；记录包含试听方案和算法版本，暂不自动训练或调整推荐。

新增「和弦 → Riff 工坊」：输入 `1645` 或 `C–Am–F–G` 写入当前段落；选择舒缓分解、切分律动或旋律钩子，生成跟随和弦的 1–2 小节单声部动机。支持独奏/合听/循环、分别换节奏或音高、音符网格、独立 MIDI 轨与本段 WAV 参考片段。动机设置进入保存、撤销、JSON 与 Suno 蓝图。

新增轻量和弦挖掘：受约束搜索三组不同方向的四和弦候选，展示连接距离、假定音色粗糙度、POP909 转移信息与内置模板差异。它们是筛选线索，不是“好听分数”或原创保证；当前是规则与语料辅助算法，尚无训练好的审美模型。[研究依据与后续验证](HARMONY_RESEARCH.md)。

当前 MVP 已实现：

- ABA、AABA、ABAB、ABABCB、ABCBA、ABACA 与自定义曲式。
- 大调/小调、12 个主音和 8 类风格语境。
- 结构驱动、固定随机种子的整曲和弦生成。
- 13 个命名和弦走向原型、听感说明与适用段落。
- 重复段落变体、和弦替换与整曲移调。
- A/B/C 主题锁定与局部重新生成；同字母再现段会联动更新，全局重编织保留锁定主题。
- 最多 48 步轻量撤销/重做，以及单槽浏览器本地项目保存与恢复。
- 导入 ChordFlow 导出的裸 JSON 或版本化本地工程 JSON；文件在浏览器内校验，不上传云端。
- 会话内 A/B 双快照：可覆盖记录、快速切换，并汇总曲式、调性、和声、低音与制作参数差异。
- 逐段制作锁定：每个主歌、副歌、桥段可独立锁定 0–100 能量、稳定/流动/戏剧三档声部路径，以及留白 `AIR`、承托 `CORE`、展开 `LIFT` 三档配器密度。
- 风格敏感的配器蓝图：相同密度会根据华语流行、独立流行、R&B、摇滚、民谣、电影配乐、爵士流行与电子氛围改写为具体乐器动作，并生成整曲 `TEXTURE ARC`。
- 轻量提示词体检：在 Suno Bridge 内显示 `READY / REVIEW`、风格提示与蓝图字符预算，并标记高能量留白、低能量满配等需要人工确认的制作反差。
- 全风格固定简报回归：8 类风格均有可复现基线，覆盖大小调、3/4 与 6/8、快慢速度、三档声部路径和 `ABACABA` 自定义长曲式；详细快照与紧凑指纹共同锁定制作措辞、配器弧线、体检结果及完整蓝图/TXT 包。
- 零新增依赖的 Chrome 工作流回归：本地项目流程覆盖 A/B 快照、撤销/重做、浏览器保存与真实 JSON 导入；Suno 交付流程覆盖剪贴板、逐段锁定和 TXT 下载；制作一致性流程读取真实 JSON/MIDI，并通过播放调度回归验证 BPM、拍号、小节数、声部与能量跨出口同步，同时确认配器密度不会生成虚假 MIDI 音轨。
- 低音与段落交付一致性：手动低音锚点同步进入 Suno `BASS ANCHORS`、试听、JSON 与 MIDI Bass Guide；不同段落可保留相反的能量、声部和配器方向；MIDI 为每个主歌、副歌和桥段写入标准 marker，便于进入 DAW 后定位结构。
- 和弦河流、下一和弦概率分支、五度圈和整曲时间线。
- 单和弦、走向与整曲试听，以及 MIDI、JSON 导出。
- 次属和弦、导音减七、调式借用等段落边界加工。
- POP909 909 首真实和弦语料统计，共 100,233 个折叠和弦事件。
- Harmonix Set 912 首真实曲式统计，共 9,675 个功能段落。
- 可点击曲式图谱、段落平均位置/时长和下一段条件概率。
- 轻量 Suno Bridge：中英文风格提示词、分段和弦蓝图、一键复制与 TXT 文件包。
- 共享制作参数：可编辑 50–180 BPM、4/4、3/4、6/8 拍号与每段 2/4/8 小节，提示词、试听、JSON 和 MIDI 使用同一组数据。
- 三档声部路径：稳定原位、平滑声部连接与戏剧化转位；同步生成斜杠和弦提示和独立 MIDI 低音轨。
- 当前和弦可选择 `AUTO` 或任一合法和弦音作为低音锚点；移调时自动跟随，和弦重写时自动清理失效覆盖。

当前的熟悉度与俗套风险包含明确标注的编辑先验。POP909 负责和弦层统计，Harmonix Set 负责曲式层统计，两者不会被混合成虚假的歌曲级联合结论。

## Suno 工作流

ChordFlow 的目标输出将包括：

1. 全曲曲式、调性、速度、拍号和风格说明。
2. 主歌、副歌、桥段的和弦与能量设计。
3. 中英文简短风格提示词。
4. 分段结构化制作说明与配器建议。
5. MIDI、纯文本和 JSON 工程数据。

当前版本已提供轻量 Suno Bridge：顶部点击 `Suno Kit`，即可编辑 BPM、拍号、每段小节数和全局声部路径，并在 `SECTION DYNAMICS` 中锁定某一段的能量、声部与配器密度。逐段能量会同步改变试听与 MIDI 力度，逐段声部会改变真实转位和低音规划；`AIR / CORE / LIFT` 会结合当前风格改写为具体乐器动作，蓝图顶部的 `TEXTURE ARC` 则压缩表达整曲从留白到展开的配器弧线。紧凑的 `PROMPT CHECK` 会显示内部字符预算并提示值得复核的能量—配器组合；它是创作辅助，不代表 Suno 官方限制，也不会阻止用户保留有意设计的反差。Suno 蓝图以 `LOCKED` 标记需要保留的段落制作方向。配器密度进入提示词、TXT 和 JSON 工程，但不会伪装成 MIDI 音轨控制；转位、斜杠和弦、自动低音线与手动低音锚点仍同步进入整曲试听、JSON 和双轨 MIDI。该能力完全在浏览器本地运行，没有后端和额外模型依赖。

在页面底部的整曲结构中，可锁定 A/B/C 主题或只重新生成某个主题。锁定信息保存在 Arrangement 与 JSON 中，不影响 Suno 提示词的简洁度。

顶部下方的 `LOCAL SESSION` 工具条用于撤销、重做、JSON 导入、保存、恢复和 A/B 对比。项目只保存在当前浏览器的一个版本化本地槽位中，不上传云端，也不引入账号与数据库；A/B 快照仅存在于当前页面会话。导入与方案切换都会进入撤销历史，但不会自动覆盖本地保存槽。支持 `⌘/Ctrl + Z`、`⌘/Ctrl + Shift + Z` 与 `⌘/Ctrl + S` 快捷键；惊喜度滑杆作为生成参数预览，不会堆积大量无意义历史步骤。

即使提示词包含完整和弦信息，Suno 的执行仍存在模型不确定性；需要逐小节精确还原时，应同时导出 MIDI 或进入 DAW 制作。

## 运行

~~~bash
npm install
npm run dev
~~~

测试与生产构建：

~~~bash
npm test
npm run build
npm run test:prompts
npm run test:e2e
~~~

当前自动测试：115 项单元/领域测试，其中 8 项为固定 Suno 创作简报回归；真实 Chrome 工作流覆盖本地项目、Suno 交付、次属输入、预示音、Riff 播放与 MIDI/WAV 下载、纯音频留白、问答与动机变体切换和撤销恢复、独立变体版本保存、模板对照与判断依据导出、主题动机和连段游标、跨段引入音、单段/整曲 MIDI 一致性与后段静音联动；新增重音切换保持音符位置、力度撤销保存与 MIDI 数值一致。`test:e2e` 不新增 Playwright 等依赖，需要 Node.js 22+ 与本机 Chrome/Chromium；非标准安装位置可通过 `CHORDFLOW_CHROME_PATH` 指定。
